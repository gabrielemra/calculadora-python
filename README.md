# Calculadora Python

Calculadora simples feita em Python, rodando no terminal. Suporta as quatro operações básicas (soma, subtração, multiplicação e divisão) e permite fazer várias contas seguidas sem precisar reiniciar o programa.

## Como funciona

O programa fica em loop pedindo dois números e uma operação, até o usuário digitar `sair`. Também trata erros comuns, como divisão por zero e valores que não são números.

## Como rodar

1. Tenha o Python instalado
2. Baixe o arquivo `calculadora.py`
3. No terminal, rode:

\`\`\`
python calculadora.py
\`\`\`

## O que pratiquei aqui

- Estruturas condicionais (`if`, `elif`, `else`)
- Loops (`while`) e controle de fluxo (`break`, `continue`)
- Tratamento de erros com `try`/`except`
- Conversão de tipos (`float`, `input`)
